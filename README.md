# 📝 NoteNest

> A simple and beginner-friendly notes application built while learning React.

NoteNest is a responsive notes web application that allows users to create and manage notes through a clean and minimal interface.

The project was built as a practical React learning project, focusing on components, state management, form handling, events, arrays, and responsive UI development.

## 📖 About

NoteNest is a beginner-friendly React project designed to provide practical experience while learning modern frontend development.

The main goal of this project was not only to build a notes application, but also to understand how React works in a real project.

Through NoteNest, you can practice:

- Creating reusable React components
- Managing data with state
- Handling forms
- Handling user events
- Adding and deleting notes
- Rendering dynamic content
- Working with arrays and objects
- Creating responsive layouts
- Building interfaces with Tailwind CSS

---

## ✨ Features

| Feature | Description |
|---|---|
| 📝 Create Notes | Add a note with a title and description |
| 🗂️ Recent Notes | Display created notes in a card-based layout |
| 🗑️ Delete Notes | Remove notes from the Recent Notes section |
| 📱 Responsive UI | Works across different screen sizes |
| 🎨 Minimal Design | Clean and simple interface |
| ⚡ React State | Notes are dynamically managed using React state |
| 📜 Scrollable Notes | Notes sections support scrolling when content increases |
